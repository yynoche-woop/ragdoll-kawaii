「ラグドール 飼っ て 後悔」。検索候補にこれが出てくると、迎える前の人はドキッとする。取材班も最初はドキッとした。でも中身を見ていくと、後悔の理由はだいたい決まっている。そして、だいたい事前に準備できる。

## 結論

「後悔した」と言われる理由は、ほとんどが次の4つだ。

1. 抜け毛が想像以上だった
2. 思ったより大きくなった(そして成長が長い)
3. 「ぬいぐるみみたいにおとなしい」と思っていたら違った
4. 医療費やお世話の費用がかかった

どれも「ラグドールだからダメ」という話ではなく、<strong>思っていたのと違った</strong>というギャップの話だ。先に知っておけば、準備で減らせる。

## 詳しく

### 1. 抜け毛:長毛種なので、抜ける

ラグドールは長毛種で、季節の変わり目には毛がごっそり抜ける。CFAの紹介では、下毛は少なめで、お手入れは週1〜2回のコーミングが目安とされている。とはいえ「手入れがいらない」わけではない。わきの下やおしりは毛玉ができやすい。対策は<a href="/columns/shedding-matting/">抜け毛・毛玉対策</a>、夏と冬の変身ぶりは<a href="/columns/summer-winter-coat/">夏毛と冬毛で別の猫になる問題</a>で。

### 2. 大きさ:オスは9kg前後になる子も

CFAの紹介では、大人のオスが20ポンド(約9kg)に届いたり超えたりするのは珍しくない。しかも<strong>体が完成するのは4歳ごろ</strong>と成長がゆっくり。子猫用に買ったキャリーやトイレが、1〜2年で小さくなることはよくある。抱き上げると重いので、動物病院に連れて行くのも一苦労だ。体重の目安は<a href="/columns/weight-by-age/">月齢別の体重</a>。

### 3. 性格:「おとなしい」は保証されない

「ラグドールはおとなしくて抱っこ好き」という紹介は多い。でも実際は個体差が大きい。猫種ごとの性格を調べた研究(Salonenら、2019年)では、ラグドールは活動量が少なめのグループに入ったが、それは平均の話で、性格が遺伝で決まる度合いは半分くらい。抱っこ嫌いの子も、よく鳴く子も、夜に走り回る子も普通にいる。検証は<a href="/columns/hates-cuddles/">抱っこを拒否</a>、<a href="/columns/voice-gap/">鳴き声問題</a>、<a href="/columns/night-zoomies/">夜の大運動会</a>で。

### 4. 費用と健康:長い付き合いになる

アニコム損保の調査では、2025年に猫1頭にかけた年間支出は<strong>約19.5万円</strong>(うち治療費は約4.7万円)。これは保険契約者へのアンケートで、猫種を問わない平均なので、あくまで目安だ。大きな猫はフードもトイレ砂もそれなりに減る。

そして、猫の平均寿命は<strong>14.5歳</strong>(アニコム 家庭どうぶつ白書2025)。10年以上の付き合いになる前提で、毎月の費用を考えておきたい。

健康面では、ラグドールは肥大型心筋症(HCM)に関わる遺伝子変異が報告されていて、遺伝子検査ができる。詳しくは<a href="/columns/health/">ラグドールがかかりやすい病気</a>、迎え方と値段の話は<a href="/columns/price/">値段はなぜ幅がある?</a>にまとめた。

## 目安の表

| 後悔の理由 | 事前にできること |
|---|---|
| 抜け毛 | ブラシ・掃除機・粘着ローラーを先に用意。ブラッシングの時間を毎日の予定に入れる |
| 大きさ | キャリーとトイレは大型用を選ぶ。4歳ごろまで育つ前提で考える |
| 性格 | 見学で実際の性格を見る。「おとなしい品種」という前提を捨てる |
| 費用 | 年間20万円前後を目安に、医療費の備え(保険や積み立て)を考える |
| 健康 | 親猫のHCM遺伝子検査の結果を確認。迎えたら早めに健康診断 |

(金額は目安。住んでいる地域や猫の体質で大きく変わる)

## 受診や相談の目安

- 迎えたら、症状がなくても早めに動物病院で健康チェックを受ける。心臓の検査について相談しておく
- 寝ているときの呼吸が速い、口を開けて呼吸している、後ろ足が急に動かない、といった様子はすぐ動物病院へ連絡
- 毛玉が皮膚に張りついて取れない、皮膚が赤いときは、無理に切らずに動物病院やトリミングの専門家に相談する
- 「思っていたのと違う」と感じたら、ひとりで抱え込まず、ブリーダーさんやかかりつけの獣医師に相談する

ちなみにラグドールにハマった人は、気づくとサイベリアンやメインクーンの動画まで見ている。後悔するとしたら、たぶんそっちの沼の深さのほうだ。
