# 週刊ラグドール コラム執筆ルール

コラムでアクセスを集めるのが基本モデル。アメショの森(別サイト)とはトーンも切り口も変える。

## ファイル
- `src/content/columns/<slug>.md`(slug は下の一覧のとおり。勝手に変えない)
- frontmatter(YAML)は必ずこの形:

```yaml

description: "……"                          # 80〜120字。記事の結論がわかる文
pubDate: 2026-09-25
category: kensho                            # kensho(検証コラム) / jitsuyo(実用)
tags: ["性格", "体"]                         # 2〜4個
verdict:
  type: kochou                              # hontou(本当) / uso(ウソ) / usoyori(ウソ寄り) / kotai(個体差) / kochou(誇張) / warito(わりとホント)
  label: "判定:誇張"                          # 画面に出る判定。「判定:」で始める
  summary: "溶けてはいない。でも溶けて見える理由はちゃんとある。"   # 1〜2文の結論
face: { coat: seal, pattern: bicolor, expr: wow }   # 記事の顔イラスト。coat: seal/blue/chocolate/lilac/red/cream、pattern: colorpoint/mitted/bicolor、expr: normal/smug/wow/sleepy

  - { title: "CFA Ragdoll Breed Standard", url: "https://cfa.org/wp-content/uploads/2024/03/ragdoll-standard.pdf" }
draft: false
---
```

## 本文の型(検証コラム)
1. 冒頭2〜3文:ウワサの紹介(アホっぽく)
2. `## ウワサ` どこでどう言われているか(X・ニュースで話題の型。個人の投稿を引用しない、要約する)
3. `## 取材班が調べた` 事実。`###` の小見出しで2〜4個。数字は幅を持たせて「目安」
4. `## 判定` 判定と理由
5. `## 飼い主向けメモ` 実際に役立つこと(箇条書き3〜5個)
6. 最後の1文はオチ(アホっぽく)

実用コラム(category: jitsuyo)は、2〜5 を「結論 → 詳しく → 目安の表 → 受診や相談の目安」の順でよい。ノリは控えめに。

- 長さ:本文 2,000〜3,500字
- 表を1つ入れられるなら入れる(Markdownの表)
- サイト内リンクは下の slug 一覧の記事だけ `<a href="/columns/<slug>/">…</a>` で張る。トップの毛色図鑑は `<a href="/#wanted">毛色図鑑</a>`、ウワサ検証は `<a href="/#rumors">ウワサ検証</a>`
- 太字は `<strong>…</strong>` を使う(日本語のカッコや句読点と ** が隣り合うと太字にならないため)

## トーン
- 文体は、だ・である寄りのくだけた口調(サイトの既存文と合わせる)。例:「5kgのお米より重いこともある。」「持ち上げると『えっ、まだ続くの?』ってくらい長い。」
- アホっぽくてOK。日本語が多少おかしくてもOK(運営者の方針:猫好きは頭おかしい)
- ただし「可愛い押し」一辺倒にはしない。「可愛いかは知らん。長い。」くらいの距離感
- 他の猫種を下げない。ラグドールや飼い主をバカにしない(愛のあるツッコミ)
- 猫好きを怒らせない:明らかな俗説(痛みを感じない、宇宙人由来など)は「ウソ」とはっきり言い切る
- 各記事に1〜2か所、自然に散りばめる方向性(運営者の方針):
  - 「長毛種が好きな人は、ほかの長毛種も好きになる」(例:ラグドールにハマった人は、たいていメインクーンやノルウェージャンやサイベリアンの動画も見ている)
  - 「猫好きは結局ぜんぶの猫が好き」(例:比べ始めた時点で全員かわいい、どの猫も優勝)
  - 押しつけず、オチや一言ツッコミとして入れる。他の猫種を下げる比較はしない

## 情報の正確さ(最重要)
- 事実として書くのは確かなことだけ。品種の基準(CFA/TICA/FIFe/GCCF/WCFの公式標準)、獣医師監修の記事、学術情報、公的機関を優先して調べる
- 性格は「よく言われる」と「実際は個体差」を分ける。「おとなしい・のんびり・鳴かない」を事実として書かない(運営者いわく大嘘)
- 数字(体重・費用・温度・回数)は幅を持たせて「目安」と書く
- 診断・薬・治療法を断定しない。健康の話には受診の目安を書く
- 自信のない事実は書かない
- 出典は `sources` に 3〜6件(実際に開いて内容を確認したURLだけ)
- 他サイトの文章をコピーしない。要約・言い換えのみ。引用は1か所15字以内まで
- バズった飼い猫の話は、ニュース記事へのリンクで紹介する(写真の転載・個人アカウント名の記載はしない)
